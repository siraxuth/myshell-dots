# Notification sounds

The notification chimes are CC0 1.0 sounds from SFXMint:

- `notification-soft.wav`: Triple-Tone Notification Chime 52, https://sfxmint.com/dl/ui-chime-52.mp3
- `notification-crisp.wav`: Notification Chime 05, https://sfxmint.com/dl/ready-chime-05.mp3

The originals were MP3 files. They were converted with FFmpeg to mono, 44.1 kHz, 16-bit PCM WAV for Qt SoundEffect playback. No other processing was applied. SFXMint describes its sounds as AI-generated or procedurally synthesized. License: https://sfxmint.com/ (CC0 1.0).
